# Fitnify 🏋️‍♂️

**Fitnify** is a modern fitness web application built with Next.js. It helps users stay motivated and track their fitness progress by providing access to various workouts, exercise categories, and personalized plans. Designed with a clean and responsive UI, Fitnify delivers an engaging experience across all devices.

## 🚀 Features

- 🏃 Browse a wide variety of exercises by muscle group.
- 🤖 AI-powered workout recommendations.
- 📱 Responsive design for desktop and mobile use.
- ❤️ Save favorite exercises (coming soon).
- 📅 Create and manage a workout plan (in development).

## 🛠️ Tech Stack

- **Framework:** [Next.js](https://nextjs.org/)
- **Frontend:** [React](https://reactjs.org/), [Framer Motion](https://wwwC.framer.com/motion/)
- **AI:** [OpenAI](https://openai.com/), [Hugging Face Inference](https://huggingface.co/docs/inference-client/index)
- **Styling:** CSS Modules / PostCSS

## 📦 Installation & Setup

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/yourusername/fitnify.git
    cd fitnify
    ```

2.  **Install dependencies:**
    ```bash
    npm install
    ```

3.  **Set up environment variables:**
    Create a `.env.local` file in the root of the project and add your API keys:
    ```
    OPENAI_API_KEY=your_openai_api_key
    HUGGINGFACE_API_KEY=your_huggingface_api_key
    ```

4.  **Run the development server:**
    ```bash
    npm run dev
    ```

    Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
